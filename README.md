# 🔐 IAM Security System

A working Identity and Access Management system built in Python.

## 🎯 What This Project Does
- Login system with username and password
- MFA with OTP verification
- RBAC — 3 roles with different permissions
- Admin, User and Guest access levels

## 🛠️ Tech Used
- Python 3
- RBAC concepts
- MFA implementation

## 👩‍💻 How to Run
- python main.py
- Enter username and password
- Enter OTP when prompted
